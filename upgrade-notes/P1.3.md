# P1.3 — TenantEventStoreDecorator.StreamAll now throws

## What changed

`TenantEventStoreDecorator.StreamAll()` (the request-scoped event store in multi-tenant mode)
now throws `InvalidOperationException` instead of silently forwarding to `StreamAllTenants`.

This is an **interim guard**. A full interface split that formally separates the tenant-scoped
`IEventStore` from the consumer-feed backend is planned for a later breaking-changes phase.

## Why

The previous behaviour was a silent data-isolation violation: any request-scoped code that
called `eventStore.StreamAll()` (e.g. via `IEventStore` injection, or via a projection that
called `AppendAsync` + `StreamAll` in one handler) would receive events for **all tenants**,
not just the active one. The caller had no indication that cross-tenant data was returned.

## Impact

**Breaking only in multi-tenant mode (`WithTenancy()` active).** Single-tenant deployments are
unaffected (their backend is `PostgresEventStoreBackend`, not `TenantEventStoreDecorator`).

Any code that calls `StreamAll()` on the keyed `IEventStore` / `IEventStoreBackend` in a
multi-tenant context will receive an `InvalidOperationException` at runtime with a message
explaining the issue.

## Migration

`StreamAll` on the request-scoped store was always semantically wrong in tenant mode.
There are two correct replacements:

### Option A — use the consumer-feed backend (background loops)

Background services such as `ControlLoop` and `DeadLetterRetryLoop` already use the
`":consumer"`-keyed backend which calls `StreamAllTenants` correctly. Register your own
background work against that same key:

```csharp
// In a singleton background service
var backend = sp.GetRequiredKeyedService<IEventStoreBackend>(moduleKey + ":consumer");
await backend.StreamAll(afterPosition: lastPosition, ct: ct);
```

### Option B — query the tenant-scoped stream (request handlers)

If a request handler genuinely needs to scan history for the active tenant, call `Stream` with
an unrestricted query instead:

```csharp
// Returns events for the current tenant only — correct in a request-scoped context
await eventStore.StreamAsync(DcbQuery.Any(), afterPosition: 0, ct: ct);
```

The full interface split (tracked as finding P3.1) will make this distinction compile-time
safe by expressing the two backends as separate interfaces.
